# 霍格沃茨小手机

纯静态网页,没有后端,没有构建步骤。玩家自己填 AI 接口的 Key,存档只保存在自己浏览器里。

## 文件
index.html / style.css / data.js(角色、节日、课程表、分院题)/ store.js(存档)/ ai.js(调用接口)/ app.js(所有页面)

## 部署到私有仓库
1. GitHub 新建仓库,选 Private,把本目录所有文件上传到仓库根目录。
2. 在 Cloudflare Pages(或 Vercel / Netlify)里连接该私有仓库,构建命令留空,输出目录填 `/`。
3. 得到链接后,玩家用手机打开,填入自己的 API Key 即可。建议 iPhone 用户「添加到主屏幕」。
4. 不要把你自己的 Key 写进任何文件。

## 已完成
入学通知书(登录后只播一次,退出登录后重播)、分院测试(每周一次)、上滑解锁、桌面与课程表小组件、聊天(亲密度/信任度)、电话(打字 + 语音朗读)、日历(HP 节日)、外观(5 套配色)、设置(角色卡、接口、存档导入导出)。
